EVENTS IN BLOOM — LOGO FILES
Rebuilt September 2026

TYPEFACES (both open-licensed, OFL — free for commercial use)
  Script  Great Vibes
  Serif   Cormorant Garamond (tagline, caps, 0.44em tracking)
All type in the SVG files is converted to outlines, so no fonts
need to be installed to open, print, or edit them.

COLOR
  Ink    #14120F
  Ivory  #FDFCFA

FOLDERS
  svg/   Vector. Use for print, signage, embroidery, vinyl, and web.
  png/   Transparent raster. 1x/2x/4x for screen, print-300dpi for print.

WHICH FILE TO USE
  Website header, wide spaces ....... eib-horizontal-black.svg
  Dark backgrounds .................. eib-horizontal-white.svg
  Square or narrow spaces ........... eib-stacked-black.svg
  Small sizes, no tagline ........... eib-wordmark-black.svg
  Social avatar, favicon ............ eib-favicon-dark.svg (+ png 32/64/180/512)
  Email signature ................... eib-email-signature.svg (+ png 600/1200)
  Stamp, watermark, accent .......... eib-sprig-black.svg

RULES
  Minimum width for the full lockup: 1.4 in / 130 px. Below that use
  the wordmark or monogram. Clear space on all sides equals the height
  of the capital E. Do not recolor, stretch, rotate, outline, or add
  shadows, and never detach the leaf sprig from the final M.
